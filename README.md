# Spam Email Classifier

A machine learning project that classifies emails as SPAM or HAM.

## Technologies Used
- Python
- Scikit-learn
- Pandas

## How it Works
- TF-IDF converts text into numerical features
- Multinomial Naive Bayes classifies messages
- Achieves ~87.5% accuracy

## How to Run
1. Install dependencies:
   pip install scikit-learn pandas
2. Run the script:
   python spam_email_classifier.py# spam-email-classifier
